
# ABYSS Dashboard

Dashboard do sistema social interno da equipe ABYSS.

## Funcionalidades

- Visualização de publicações.
- Estatísticas de curtidas e comentários.
- Configuração do perfil.
- Seleção do canal de publicações.
- Controle de curtidas.
- Controle de comentários.
- Controle de compartilhamentos.
- Integração com bot Discord.

## Estrutura

- index.html
- style.css
- config.js
- app.js

## Instalação

1. Crie um repositório no GitHub.
2. Envie os arquivos para a raiz do repositório.
3. Abra Settings.
4. Entre em Pages.
5. Em Build and deployment, selecione GitHub Actions.
6. Configure o endereço da API em config.js.

## Backend

O backend precisa ser hospedado separadamente.

O GitHub Pages hospeda somente o frontend estático. Ele não executa o bot Discord nem o servidor Node.js.

## Segurança

Nunca coloque o token do Discord no frontend.
Nunca publique sua chave privada no GitHub.
